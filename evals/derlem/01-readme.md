# Görev takip aracı

Bu araç, küçük ekiplerin günlük işlerini tek bir listede toplamasına yardım ediyor. Kurulumdan sonra her görev için bir başlık, sorumlu kişi ve bitiş tarihi giriyorsunuz. Liste değiştiğinde ekipteki herkese kısa bir bildirim gidiyor.

## Kurulum

Önce depoyu indirin, sonra bağımlılıkları yükleyin:

```bash
git clone https://example.com/gorev-takip.git
cd gorev-takip && npm install
```

Ayarlar `config.json` dosyasında duruyor. Varsayılan dil Türkçe; isterseniz İngilizceye geçebilirsiniz.
